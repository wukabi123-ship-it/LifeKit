What Is PDF Merging?

PDF merging combines two or more PDF files into a single PDF document. This can make documents easier to organize, store, share and submit as one file instead of several separate files.

How to Merge PDF Files

  1. Add the PDF files you want to combine.
  2. Arrange the files in the order you want.
  3. Start the PDF merge process.
  4. Download the resulting PDF document.

When Is PDF Merge Useful?

Merging can be useful for school assignments, project documents, applications, reports, scanned paperwork and other situations where related PDF files need to be collected into one document.

Why Combine PDFs Into One File?

A single PDF can be easier to send, upload and organize. For example, several related documents can be combined into one file before submitting or sharing them.

Check Your File Order

Before merging, check that the files are arranged in the correct order. The final PDF follows the order selected in the tool.

Frequently Asked Questions

How many PDF files can I merge?

You can select multiple PDF files. The available limits depend on your browser and device.

Can I change the order of the PDF files?

Yes. Arrange the files in the order you want before merging them so the final document follows that order.

Can I merge scanned PDF files?

PDF files can be merged regardless of whether their pages contain scanned documents or digitally created content, provided the files are supported by the tool.

What happens to my original PDF files?

The original files you select are not replaced by the merged document. A separate merged PDF is created for you to download.

Why would I merge PDFs instead of keeping them separate?

Combining related files can make them easier to upload, share, store and manage as one document.
