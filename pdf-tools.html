Free Online PDF Tools

PDF files are useful for documents, school work, forms, applications and sharing information. However, working with PDFs can sometimes require simple tasks such as combining files, removing pages, reducing file size or converting pages into images.

What can you do with these tools?

  • Merge several PDF files into one document.
  • Split a PDF or extract selected pages.
  • Compress a PDF to reduce its file size.
  • Convert PDF pages into JPG images.
  • Convert JPG images into a PDF document.

When are PDF tools useful?

These tools can be useful when preparing school assignments, organizing documents, submitting forms, sharing files online, creating simple document collections or converting documents between PDF and image formats.

How to choose the right tool

Need to combine files? Use PDF Merge. Need only certain pages? Use PDF Split. Need a smaller file? Use PDF Compress. Need an image version of a PDF page? Use PDF to JPG. Need to turn several images into a document? Use JPG to PDF.

Frequently Asked Questions

Are these PDF tools free to use?

LifeKit provides these PDF tools as free online utilities. Open a tool above to see its available features.

Which PDF tool should I use to combine files?

Use PDF Merge when you want to combine multiple PDF files into a single document.

How can I remove or extract PDF pages?

Use PDF Split to work with individual pages or separate parts of a PDF file.

Which tool can make a PDF smaller?

Use PDF Compress when you need to reduce the file size of a PDF.

Can I convert a PDF page into an image?

Yes. Use PDF to JPG to convert PDF pages into JPG images.

Can I turn JPG images into a PDF?

Yes. Use JPG to PDF to create a PDF document from image files.
