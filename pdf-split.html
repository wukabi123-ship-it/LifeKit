What Is PDF Splitting?

PDF splitting separates pages from an existing PDF document. Instead of keeping an entire document together, you can extract only the pages you need or divide a larger PDF into smaller PDF files.

How to Split a PDF

  1. Upload the PDF file you want to split.
  2. Choose a split mode.
  3. Select the pages you need or choose how many pages each new file should contain.
  4. Start the split process.
  5. Download the resulting PDF files.

Extract Selected Pages

Use this option when you only need certain pages from a larger document. You can enter individual page numbers, such as 2 or 7, or use ranges such as 1-3 and 8-10.

Split Every N Pages

This option divides the document into smaller PDF files containing a chosen number of pages each. It can be useful when a large document needs to be separated into several smaller sections.

When Is PDF Split Useful?

Splitting a PDF can be useful for school assignments, reports, scanned documents, applications, forms and other files where only certain pages need to be shared or stored separately.

Check the Pages Before Downloading

Before starting the split, review the selected pages or page grouping. This helps make sure the resulting files contain the pages you actually need.

Frequently Asked Questions

Can I extract only a few pages from a PDF?

Yes. Choose Extract Selected Pages and enter the page numbers or ranges you want to keep.

How do I select a range of pages?

Use a hyphen to define a range. For example, 1-5 selects pages 1 through 5.

Can I select individual pages?

Yes. Separate individual page numbers with commas, such as 1, 4, 7.

What does Split Every N Pages mean?

It divides the original PDF into multiple files, with each file containing the number of pages you specify.

Does splitting change my original PDF?

No. The original file remains separate from the PDF files created by the split operation.

Can I split a large PDF?

The practical file size and processing limit depends on your browser, device memory and the PDF itself.
